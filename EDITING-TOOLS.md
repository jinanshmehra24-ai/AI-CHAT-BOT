# Free Editing Tools from GitHub

These are open-source tools that are popular (thousands of stars) and actively maintained. Star counts were checked in Nov 2026.
✅ = already installed by this toolkit. 🎮 = needs a good NVIDIA GPU (or runs very slowly without one).

Only download from the official GitHub **Releases** page or the official website linked in each repo.
Fake copies with similar names are a common way to spread malware.

## Video editors
| Tool | ⭐ | Use it for |
|---|---|---|
| [OpenCut](https://github.com/OpenCut-app/OpenCut) | 97k | Free open-source **CapCut alternative**, the easiest switch from CapCut |
| [Shotcut](https://github.com/mltframework/shotcut) | 16k | Simple, light editor that runs on weak laptops |
| [Kdenlive](https://github.com/KDE/kdenlive) ✅ | 6k | Full multi-track editor with effects and titles |
| DaVinci Resolve (free, not on GitHub) | — | Industry-standard pro editor and colour grading, best for client work |

## Speed up editing / automation
| Tool | ⭐ | Use it for |
|---|---|---|
| [auto-editor](https://github.com/WyattBlue/auto-editor) ✅ | 6k | Cuts silences automatically and exports timelines to Premiere/Resolve/FCP |
| [LosslessCut](https://github.com/mifi/lossless-cut) ✅ | 46k | Instant trimming of huge files with no re-render |
| [PySceneDetect](https://github.com/Breakthrough/PySceneDetect) | 5k | Auto-splits long videos at every scene change, good for making clips |

| [Subtitle Edit](https://github.com/SubtitleEdit/subtitleedit) | 15k | Fix, time and translate subtitle files for clients |
| [HandBrake](https://github.com/HandBrake/HandBrake) | 25k | Compress exports to send to clients or upload faster |

**Where to start:**
1. **Client work:** DaVinci Resolve + AutoSubs + auto-editor + Ultimate Vocal Remover.
2. **Coming from CapCut:** try OpenCut.
3. **Weak laptop:** use Shotcut and LosslessCut, and skip the 🎮 tools.
